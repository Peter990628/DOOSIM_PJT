# Three-Patient MRI Transfer Runtime

이 확장은 김서울·박인천·서수원 환자 모델을 각 운반 침대에 배치하고 MRI 환자 테이블과 침대 사이를 이동시킵니다.

- 김서울: Laying Breathless
- 박인천: Holding Stomach 모델을 눕힘
- 서수원: 별도 환자 모델
- 진입 1.25 m / 이탈 1.75 m / 유지 1.0초
- MRI 1인 점유 보호
- K: Stage에서 선택한 실제 MRI 테이블 저장
- L: 상태 출력

전체 실행법은 프로젝트 루트의 `README_KO.md`를 참조하세요.
