## 2. 최상위 구성

| 경로 | 설명 |
|---|---|
| `config/isaac_config.json` | AMR, 센서, 도킹, 엘리베이터, 환자 시나리오 설정 |
| `project4/` | 메인 병원 Stage와 환자 이름표·ArUco 에셋 |
| `scripts/` | Isaac 런타임, 도킹, 엘리베이터, ArUco, 보조 도구 |
| `ros2_ws/src/` | 빌드 가능한 ROS 2 소스 패키지 |
| `patient_mri_transfer/` | MRI 환자 이동 Isaac Extension |
| `tray_overlay/` | 트레이 협동 운송용 추가 런타임·설정·마커 |
| `templates/`, `static/` | Flask GUI 화면과 정적 파일 |
| `output/` | OCR 결과 출력 위치(빈 디렉터리 유지) |

## 3. ROS 2 패키지

### `hospital_nav2`

- AMR1/AMR2 Nav2 launch
- 고정 초기 자세 및 world pose 발행
- 복도 중앙선 기반 이동
- 경로 충돌 감지, 우선순위, 일시정지·재개
- 침대 이송 구간 공간 예약
- RViz 표시 설정

### `hospital_ocr_bridge`

- AMR별 카메라 영상 수신
- PaddleOCR 환자 이름표 판정
- ArUco/OCR 정렬 결과와 미션 launch 연결

### `hospital_tray_overlay`

- 360° LaserScan 검증
- 트레이 ArUco pair 검출
- 협동 명령 분배와 트레이 운송 관리
- 런타임·맵·토픽 상태 probe

## 5. 의존성 파일 구분

- `requirements.txt`: GUI용 Flask 의존성
- `requirements_ocr_ros.txt`: OCR용 NumPy, OpenCV contrib, PaddlePaddle, PaddleOCR, PaddleX
- `ros2_ws/src/*/package.xml`: ROS 2 런타임 의존성
- `01_install_ocr_ros.sh`: OCR 가상환경 생성과 모델 사전 다운로드
- `07_install_nav2.sh`: Ubuntu/ROS 패키지 설치

`rclpy`, ROS 메시지 패키지, Nav2는 pip requirements에 넣지 않는다.

## 6. 제출 ZIP에서 제외할 생성물

다음 항목은 소스가 아니며 평가 PC에서 다시 생성되므로 제외한다.

```text
ros2_ws/build/
ros2_ws/install/
ros2_ws/log/
**/__pycache__/
*.pyc
```

사용자 결과물이나 필요한 데이터베이스·맵·USD·이미지 에셋은 삭제하지 않는다.
