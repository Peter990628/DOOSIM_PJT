# 설치 및 실행 가이드

## 1. 압축 해제 후 확인

```bash
cd <압축을_푼_경로>/final
chmod +x ./*.sh scripts/*.sh
./check_project.sh
```

프로젝트 경로에 공백이나 괄호가 있어도 대부분 실행되지만, 문제를 줄이려면 영문·숫자·밑줄만 사용한 경로를 권장한다.

## 2. 최초 설치

ROS 2 Humble이 설치된 Ubuntu 22.04에서 진행한다.

```bash
# Nav2가 없을 때
./07_install_nav2.sh

# OCR을 사용할 때
./01_install_ocr_ros.sh

# ROS 워크스페이스 빌드
./02_build_ros_ws.sh
```

`02_build_ros_ws.sh`는 `ros2_ws/build`, `install`, `log`를 새로 생성한다. 제출 ZIP에는 이 생성 폴더를 포함하지 않고 평가 PC에서 다시 빌드한다.

## 3. Isaac Sim 경로 설정

기본 실행기는 다음 경로를 먼저 사용한다.

```text
$HOME/dev_ws/isaac_sim/isaacsim/_build/linux-x86_64/release
```

다른 위치에 설치했다면 해당 터미널에서 지정한다.

```bash
export ISAAC_SIM_DIR=/실제/isaacsim/경로
```

Isaac 터미널에서는 `/opt/ros/humble/setup.bash`를 직접 source하지 않는다. `03_run_isaac.sh`가 Isaac 내부 ROS 2 Bridge 환경을 구성한다.

## 4. 기본 GUI 통합 시연

기존 프로세스 정리:

```bash
./00_stop_all.sh
```

각 명령은 서로 다른 터미널에서 실행한다.

| 순서 | 터미널 | 명령 | 역할 |
|---:|---:|---|---|
| 1 | 1 | `./03_run_isaac.sh` | Isaac 병원 환경·AMR·센서 실행 |
| 2 | 2 | `./09_run_nav2_amr1.sh` | AMR1 Nav2 |
| 3 | 3 | `./09_run_nav2_amr2.sh` | AMR2 Nav2 |
| 4 | 4 | `./09_run_collision_avoidance.sh` | 경로 충돌 회피·공간 예약 |
| 5 | 5 | `./10_run_gui.sh` | 관제 GUI |

GUI에서 AMR과 환자를 선택하고 이동 명령을 실행한다. GUI가 미션 스크립트를 직접 시작하므로 같은 AMR의 OCR 미션을 별도 터미널에서 중복 실행하지 않는다.

GUI를 다른 PC에서 실행해도 양쪽 PC의 `ROS_DOMAIN_ID=115`, `RMW_IMPLEMENTATION=rmw_fastrtps_cpp`, `ROS_LOCALHOST_ONLY=0`이 같아야 한다.

## 5. GUI 없는 미션 실행

```bash
# AMR1: 김서울
./04_run_ocr_mission_1.sh 1

# AMR2: 박인천
./04_run_ocr_mission_2.sh 2
```

환자 번호:

| 번호 | 환자 |
|---:|---|
| 1 | 김서울 |
| 2 | 박인천 |
| 3 | 서수원 |

두 AMR에 같은 환자를 동시에 지정하지 않는다. 첫 AMR이 충전 구역을 벗어난 뒤 두 번째 미션을 시작한다.

## 6. 트레이 협동 운송 시연

최초 1회:

```bash
./00_SETUP_TRAY_360_INTEGRATED.sh
```

자동 전체 흐름:

```bash
# 터미널 1
./RUN_TRAY_1_ISAAC_TOTAL_360.sh

# 터미널 2
./RUN_TRAY_2_AUTO_TOTAL_360.sh
```

고속 기능 시연:

```bash
# 터미널 1
./RUN_V217_1_ISAAC_SCAN_READY.sh

# 터미널 2
./RUN_V217_2_TRUE_ARUCO_DOCK_TRANSPORT.sh
```

고속 모드는 병원 좁은 복도나 실제 하드웨어에 그대로 적용하지 않는다.

## 7. 상태 점검

```bash
./06_check_topics.sh
./10_check_nav2_topics.sh
ros2 topic echo /traffic_conflict/status
ros2 topic echo /traffic_reservation/status
```

트레이 모드:

```bash
./CHECK_360_LIDAR_RUNTIME.sh
./CHECK_TRAY_ARUCO_GATE.sh
```

## 8. 정상 종료

각 터미널에서 `Ctrl+C`를 누른 뒤 다음을 실행한다.

```bash
./00_stop_all.sh
```

트레이 모드만 정리하고 Isaac Sim을 유지하려면 다음을 사용한다.

```bash
./STOP_TRAY_INTEGRATED_ROS.sh
```
